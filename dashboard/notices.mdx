**공지사항**은 포토이토가 가게에 알리는 소식이 모이는 곳이에요. 점검 시간, 새로 생긴 기능, 이벤트 같은 내용이 올라와요.

왼쪽 메뉴에서 **공지사항**을 누르면 열려요. 최근 공지는 [홈](/dashboard/overview) 화면에서도 볼 수 있어요.

</Frame>

## 목록 읽는 법

한 줄이 공지 하나예요.

| 칸 | 뜻 |
| --- | --- |
| **상태** | 아직 안 읽은 공지에는 빨간 **새 공지** 표시가 붙어요. 읽은 공지는 **읽음**으로 바뀌어요. |
| **카테고리** | 공지의 종류예요. 아래 표를 보세요. |
| **제목** | 공지 제목이에요. 안 읽은 공지는 굵은 글자로 보여요. 제목 앞에 **압정 모양**이 있으면 포토이토가 맨 위에 고정해 둔 중요한 공지예요. |
| **게시일** | 공지가 올라온 날짜와 시간이에요. |

고정된 공지가 맨 위에 오고, 나머지는 새로 올라온 순서대로 보여요.

카테고리는 네 가지예요.

| 카테고리 | 어떤 공지인가요 |
| --- | --- |
| **공지** | 일반 안내예요. |
| **업데이트** | 새 기능이나 바뀐 점을 알려요. |
| **점검** | 서비스 점검 일정을 알려요. |
| **이벤트** | 이벤트 소식이에요. |

## 공지 읽기

읽고 싶은 공지의 줄을 누르면 내용이 열려요. 다 읽었으면 왼쪽 위 **목록으로**를 눌러 돌아가요.

공지를 한 번 열면 **읽음**으로 바뀌어요.

<Note>
  읽음 표시는 **가게 단위**예요. 직원이 먼저 열어 본 공지는 사장님 화면에서도 **읽음**으로 보여요. **점검** 공지처럼 중요한 내용은 직원끼리 한 번 더 알려 주세요.
</Note>

## 원하는 공지만 보기

목록 위의 **상태**(1번)와 **카테고리**(2번) 버튼으로 공지를 골라 볼 수 있어요.

<Frame>
  <img src="/images/ko/notices/filters.png" alt="공지 목록 위의 상태 버튼에 1번, 카테고리 버튼에 2번 표시가 있다." />
</Frame>

1. **상태**: **안 읽음**이나 **읽음**을 골라요. 안 읽은 공지만 모아 볼 때 써요.
2. **카테고리**: **공지**, **업데이트**, **점검**, **이벤트** 중에서 골라요. 여러 개를 함께 골라도 돼요.

<Frame caption="「카테고리」를 누른 모습">
  <img src="/images/ko/notices/filter-category.png" alt="카테고리 버튼을 눌러 공지, 업데이트, 점검, 이벤트 네 가지 선택 칸이 펼쳐져 있다." />
</Frame>

고른 것을 풀면 다시 전체 공지가 보여요.

## 잘 안 될 때

<AccordionGroup>
  <Accordion title="전에 본 공지가 사라졌어요">
    먼저 **상태**나 **카테고리**를 골라 둔 채가 아닌지 확인해 주세요. 골라 둔 것을 풀면 전체가 다시 보여요.

    그래도 없다면 게시 기간이 끝난 공지예요. 포토이토가 정한 기간이 지난 공지는 목록에서 내려가요.
  </Accordion>

  <Accordion title="안 읽었는데 「읽음」으로 나와요">
    같은 가게의 다른 사람이 먼저 열어 봤을 수 있어요. 읽음 표시는 사람마다가 아니라 가게마다 하나예요.
  </Accordion>

  <Accordion title="직원에게 「공지사항」 메뉴가 안 보여요">
    직원은 사장님이 권한을 줘야 이 메뉴를 열 수 있어요. [직원 관리](/dashboard/staff)에서 그 직원의 **권한 수정**을 누르고 **공지사항**에 체크해 주세요.
  </Accordion>
</AccordionGroup>
