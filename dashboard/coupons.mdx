**쿠폰**은 손님이 키오스크 결제 화면에서 넣는 **숫자 6자리 코드**예요. 맞는 코드를 넣으면 정해 둔 만큼 가격이 깎여요. 이 화면에서 쿠폰을 만들고, 켜고 끄고, 몇 번 쓰였는지 확인해요.

왼쪽 메뉴에서 **쿠폰 관리**를 누르면 열려요.

<Frame caption="쿠폰 관리 화면">
  <img src="/images/ko/coupons/list.png" alt="쿠폰 관리 화면. 위에 숫자 네 개, 왼쪽에 빠른 발급, 오른쪽에 쿠폰 목록이 있다." />
</Frame>

## 손님은 쿠폰을 어떻게 쓰나요?

1. 손님이 키오스크 결제 화면에서 **쿠폰사용**을 눌러요.
2. 숫자판으로 쿠폰 코드 6자리를 넣고 확인을 눌러요.
3. 가격이 깎여요.
   - 깎고도 낼 돈이 남으면, 남은 금액만 결제해요.
   - 가격 전부가 깎이면(예: 100% 할인) 결제 없이 바로 촬영으로 넘어가요.

<Warning>
  **키오스크에서 쿠폰을 한 번 켜 줘야 해요.** 키오스크는 처음에 쿠폰이 꺼져 있어요. 꺼져 있으면 결제 화면에 **쿠폰사용** 버튼이 보이지 않아요.

  키오스크에 연결된 키보드에서 **M** 키를 누르고 비밀번호 `admin123`으로 설정 화면에 들어간 뒤, **결제 설정**의 **결제 수단**에서 **쿠폰 결제**를 켜 주세요. 쿠폰을 쓸 키오스크마다 해 주세요.
</Warning>

<Note>
  한 번 결제에 쿠폰은 **하나만** 적용돼요. 쿠폰을 넣은 뒤 다른 쿠폰을 또 넣으면, 할인이 더해지지 않고 나중에 넣은 쿠폰으로 바뀌어요.
</Note>

## 화면 읽는 법

<Frame>
  <img src="/images/ko/coupons/list-parts.png" alt="쿠폰 관리 화면. 위쪽 숫자 줄에 1번, 왼쪽 빠른 발급에 2번, 목록 위 구분 버튼에 3번 표시가 있다." />
</Frame>

1. **숫자 네 개**: 쿠폰이 지금 어떤 상태인지 한눈에 보여요.

   | 이름 | 뜻 |
   | --- | --- |
   | **전체 쿠폰** | 만들어 둔 쿠폰 개수예요. |
   | **활성** | 지금 손님이 쓸 수 있는 쿠폰 개수예요. |
   | **만료 임박 (7일)** | 쓸 수 있는 쿠폰 중에서, 끝나는 날이 7일 안으로 남은 쿠폰 개수예요. |
   | **누적 사용** | 손님이 쿠폰을 써서 결제를 마친 횟수를 모두 더한 값이에요. |

2. **빠른 발급**: 자주 주는 쿠폰을 버튼 한 번으로 만드는 곳이에요. 쓰지 않아도 돼요. 아래 [빠른 발급](#빠른-발급-쓰지-않아도-돼요)에서 설명해요.

3. **구분 버튼**: 누르면 그 종류의 쿠폰만 보여요. **전체**, **활성**, **만료임박**, **공용**(여러 가게에서 같이 쓰는 쿠폰), **가게 고유**(한 가게에서만 쓰는 쿠폰)가 있어요. 그 위의 **코드·이름 검색** 칸에 쿠폰 코드나 이름을 넣어 찾을 수도 있어요.

목록의 한 줄이 쿠폰 하나예요.

| 칸 | 뜻 |
| --- | --- |
| **코드 / 이름** | 굵은 글자가 손님이 넣는 코드예요. 코드를 누르면 복사돼요. 그 아래가 쿠폰 이름이에요. |
| **적용 가게** | 이 쿠폰을 쓸 수 있는 가게예요. |
| **할인** | 깎아 주는 금액이나 비율이에요. |
| **상태** | **활성**(지금 쓸 수 있음), **예정**(시작일이 아직 안 됨), **만료**(종료일이 지남), **비활성**(꺼 둠) 중 하나예요. |
| **기간** | 쓸 수 있는 시작일과 종료일이에요. |
| **사용** | 「쓰인 횟수/쓸 수 있는 횟수」예요. `104/300`은 300번 중 104번 쓰였다는 뜻이에요. `∞`는 횟수 제한이 없다는 뜻이에요. |

## 쿠폰 만들기

<Steps>
  <Step title="「쿠폰 추가」를 눌러요">
    쿠폰 목록 오른쪽 위에 있어요.

    <Frame>
      <img src="/images/ko/coupons/add-button.png" alt="쿠폰 목록 오른쪽 위의 쿠폰 추가 버튼에 빨간 표시가 있다." />
    </Frame>
  </Step>

  <Step title="쿠폰 이름과 할인을 적어요">
    <Frame>
      <img src="/images/ko/coupons/create-dialog.png" alt="쿠폰 만들기 창. 쿠폰명에 첫 방문 1,000원 할인, 할인 타입에 고정 금액, 할인 값에 1000이 적혀 있다." />
    </Frame>

    - **쿠폰명**: 사장님이 알아보기 위한 이름이에요. 꼭 적어야 해요.
    - **수량**: 만들 쿠폰 개수예요. 보통은 1 그대로 두세요. 여러 개를 만들면 코드가 서로 다른 쿠폰이 그만큼 생겨요. 한 번에 500개까지 만들 수 있어요.
    - **할인 타입**: 깎는 방법을 골라요.
      - **퍼센트 (%)**: 가격의 몇 %를 깎아요. 1부터 100까지 넣을 수 있어요. 100을 넣으면 무료예요.
      - **고정 금액**: 정한 금액만큼 깎아요. 가격보다 큰 금액을 넣어도 가격까지만 깎여요.
    - **할인 값**: 깎을 비율이나 금액이에요.
  </Step>

  <Step title="쿠폰 코드를 정해요 (안 해도 돼요)">
    그대로 두면 코드가 **자동으로** 만들어져요. 무작위 숫자 6자리예요.

    원하는 숫자로 정하고 싶다면, **코드 자동 생성(랜덤 6자리)** 의 체크를 풀고(1번) **쿠폰 코드** 칸(2번)에 숫자 6자리를 적어요.

    <Frame>
      <img src="/images/ko/coupons/create-code.png" alt="쿠폰 만들기 창. 코드 자동 생성 체크 칸에 1번, 쿠폰 코드 칸에 2번 표시가 있다." />
    </Frame>

    <Note>
      코드는 **숫자 6자리**만 돼요. 글자는 넣을 수 없어요. 수량이 2개 이상이면 직접 정할 수 없고 자동으로 만들어져요.
    </Note>
  </Step>

  <Step title="쓸 수 있는 기간을 정해요">
    **시작일**과 **종료일**을 눌러 날짜와 시간을 골라요. 처음에는 지금부터 30일 뒤까지로 들어가 있어요.

    시작일 전이나 종료일 뒤에는 손님이 코드를 넣어도 할인되지 않아요.
  </Step>

  <Step title="쓸 가게를 확인해요">
    **적용 가게**에 체크된 가게에서만 이 쿠폰을 쓸 수 있어요. 가게가 한 곳이면 그대로 두면 돼요.
  </Step>

  <Step title="「생성」을 눌러요">
    「쿠폰 발급 완료」 창에 코드가 크게 보여요. **코드 복사**를 눌러 복사한 뒤 손님에게 알려 주세요.

    여러 개를 만들었다면 코드 목록이 보여요. **CSV 다운로드**를 누르면 코드 전체를 엑셀에서 열 수 있는 파일로 받을 수 있어요.

    코드는 나중에 쿠폰 목록에서도 다시 볼 수 있어요.
  </Step>
</Steps>

### 더 세밀하게 정하기 (고급 설정)

쓰지 않아도 돼요. 창에서 **고급 설정 펼치기**를 누르면 칸이 더 나와요.

<Frame>
  <img src="/images/ko/coupons/create-advanced.png" alt="쿠폰 만들기 창에서 고급 설정을 펼친 모습. 최소 구매 금액, 최대 할인 금액, 총 사용 제한, 세션당 사용 제한, 목적 칸이 있다." />
</Frame>

| 칸 | 뜻 |
| --- | --- |
| **최소 구매 금액** | 가격이 이 금액보다 낮으면 쿠폰을 쓸 수 없어요. 0이면 제한이 없어요. |
| **최대 할인 금액** | 퍼센트 할인일 때, 깎이는 금액이 이 금액을 넘지 않게 해요. 0이면 제한이 없어요. |
| **총 사용 제한** | 이 쿠폰을 모두 합쳐 몇 번까지 쓸 수 있는지예요. 0이면 제한이 없어요. 한 번만 쓰는 쿠폰은 1을 넣어요. |
| **세션당 사용 제한** | 그대로 1로 두세요. |
| **목적** | 쿠폰을 구분하는 이름표예요. **웰컴**, **생일**, **이벤트**, **VIP**, **프로모션** 중에서 골라요. 목록에서 코드 옆에 표시돼요. 할인에는 영향이 없어요. |
| **다른 쿠폰과 중복 사용 가능** | 체크해도 키오스크에서 달라지는 것은 없어요. 한 번 결제에 쿠폰은 하나만 적용돼요. |

## 이렇게 만들어 보세요

### 첫 방문 1,000원 할인

누구나 여러 번 쓸 수 있는 코드를 하나 만들어, 가게 안내문이나 SNS에 적어 두는 방법이에요.

| 칸 | 넣는 값 |
| --- | --- |
| **쿠폰명** | 첫 방문 1,000원 할인 |
| **수량** | 1 |
| **쿠폰 코드** | 자동 생성 체크를 풀고 외우기 쉬운 숫자 6자리 |
| **할인 타입** | 고정 금액 |
| **할인 값** | 1000 |
| **총 사용 제한** (고급 설정) | 0 (제한 없음). 500번까지만 쓰게 하려면 500 |
| **목적** (고급 설정) | 웰컴 |

<Note>
  쿠폰은 「처음 온 손님인지」를 가려내지 못해요. 코드를 아는 사람은 누구나, **총 사용 제한**이 남아 있는 동안 쓸 수 있어요.
</Note>

### 행사 기간에만 쓰는 20% 할인

| 칸 | 넣는 값 |
| --- | --- |
| **쿠폰명** | 가을 행사 20% 할인 |
| **할인 타입** | 퍼센트 (%) |
| **할인 값** | 20 |
| **시작일** | 행사 첫날 |
| **종료일** | 행사 마지막 날 밤 |
| **목적** (고급 설정) | 이벤트 |

시작일을 앞날로 정해 두면, 그날이 되기 전까지 상태가 **예정**으로 보여요. 미리 만들어 두어도 손님이 일찍 쓸 수 없어요.

### 한 번만 쓰는 무료 촬영권

단골손님이나 불편을 겪은 손님에게 한 장씩 주는 쿠폰이에요.

| 칸 | 넣는 값 |
| --- | --- |
| **쿠폰명** | 무료 촬영권 |
| **수량** | 줄 사람 수만큼 (예: 10) |
| **할인 타입** | 퍼센트 (%) |
| **할인 값** | 100 |
| **총 사용 제한** (고급 설정) | 1 |

수량을 10으로 하면 서로 다른 코드 10개가 생기고, 코드마다 한 번씩만 쓸 수 있어요. 자주 준다면 아래 [빠른 발급](#빠른-발급-쓰지-않아도-돼요)에 규칙으로 만들어 두면 편해요.

## 쿠폰 끄기, 고치기, 지우기

쿠폰 줄 오른쪽 **관리** 칸에 스위치와 버튼이 있어요.

<Frame>
  <img src="/images/ko/coupons/row-controls.png" alt="쿠폰 목록 첫 줄의 스위치에 1번, 수정 버튼에 2번, 삭제 버튼에 3번 표시가 있다." />
</Frame>

1. **스위치**: 쿠폰을 켜고 꺼요.
2. **수정**: 쿠폰 내용을 고쳐요.
3. **삭제**: 쿠폰을 지워요.

### 잠깐 끄기

스위치를 누르면 바로 꺼지고, 상태가 **비활성**으로 바뀌어요. 꺼 둔 쿠폰은 손님이 코드를 넣어도 할인되지 않아요. 다시 누르면 켜져요.

행사를 잠깐 멈출 때는 지우지 말고 꺼 두세요. 쓰인 횟수가 그대로 남아요.

### 내용 고치기

<Steps>
  <Step title="쿠폰 줄의 「수정」을 눌러요" />
  <Step title="바꿀 내용을 고쳐요">
    이름, 할인, 기간, 고급 설정을 바꿀 수 있어요.

    <Frame>
      <img src="/images/ko/coupons/edit-dialog.png" alt="쿠폰 수정 창. 쿠폰 코드 칸은 흐리게 잠겨 있고 쿠폰명, 할인, 시작일, 종료일을 고칠 수 있다." />
    </Frame>

    **쿠폰 코드**와 **적용 가게**는 바꿀 수 없어요. 바꾸고 싶다면 쿠폰을 새로 만들어 주세요.
  </Step>
  <Step title="「수정」을 눌러요" />
</Steps>

### 지우기

쿠폰 줄의 **삭제**를 누르면 확인 창이 떠요. 한 번 더 **삭제**를 누르면 지워져요.

<Frame>
  <img src="/images/ko/coupons/delete-dialog.png" alt="쿠폰 삭제 확인 창. 이 작업은 되돌릴 수 없다고 적혀 있다." />
</Frame>

<Warning>
  지운 쿠폰은 되살릴 수 없어요. 다시 쓸 수도 있는 쿠폰이라면 지우지 말고 스위치로 꺼 두세요.
</Warning>

### 여러 개를 한 번에 끄거나 지우기

쿠폰 줄 맨 앞의 네모 칸에 체크하면 목록 위에 버튼이 나와요.

<Frame>
  <img src="/images/ko/coupons/bulk-bar.png" alt="쿠폰 두 개를 체크한 모습. 목록 위에 2개 선택됨이라는 글자와 비활성화, 삭제, 선택 해제 버튼이 나타나고 빨간 표시가 있다." />
</Frame>

- **비활성화**: 체크한 쿠폰을 모두 꺼요.
- **삭제**: 체크한 쿠폰을 모두 지워요. 되살릴 수 없어요.
- **선택 해제**: 체크를 모두 풀어요.

## 빠른 발급 (쓰지 않아도 돼요)

같은 조건의 쿠폰을 자주 준다면, 조건을 **규칙**으로 한 번 저장해 두세요. 그 뒤로는 **발급** 버튼만 누르면 새 코드가 바로 나와요.

예를 들어 「단골 무료 1회」 규칙을 만들어 두면, 단골손님이 올 때마다 버튼 한 번으로 한 번만 쓸 수 있는 무료 코드를 만들어 줄 수 있어요.

      <img src="/images/ko/coupons/rule-add-button.png" alt="빠른 발급 칸 오른쪽 위의 규칙 추가 버튼에 빨간 표시가 있다." />

    - **규칙 이름**: 빠른 발급 칸에 보이는 이름이에요. 예: 「단골 무료 1회」
    - **쿠폰명**: 이 규칙으로 만든 쿠폰에 붙는 이름이에요.
    - **할인 타입**, **할인 값**: 쿠폰을 만들 때와 같아요. 처음에는 100% 할인으로 들어가 있어요.
    - **유효기간(일)**: 발급한 순간부터 며칠 동안 쓸 수 있는지예요. 30이면 발급한 때부터 30일이에요.
    - **적용 가게**: 쿠폰을 쓸 수 있는 가게예요.

    **고급 설정 펼치기** 안의 **총 사용 제한**은 처음에 1로 들어가 있어요. 그대로 두면 발급한 코드마다 한 번만 쓸 수 있어요.
  </Step>

  <Step title="「규칙 저장」을 눌러요">
    빠른 발급 칸에 규칙이 한 줄 생겨요.
  </Step>
</Steps>

### 규칙으로 쿠폰 발급하기

<Steps>
  <Step title="규칙 옆 숫자 칸에 만들 개수를 적어요">
    한 개만 만들 때는 1 그대로 두세요. 한 번에 500개까지 만들 수 있어요.
  </Step>
  <Step title="「발급」을 눌러요">
    「쿠폰 발급 완료」 창에 새 코드가 보여요. **코드 복사**를 눌러 손님에게 알려 주세요.

    발급한 쿠폰은 오른쪽 쿠폰 목록에도 들어가요. 거기서 끄거나 지울 수 있어요.
  </Step>
</Steps>

### 규칙 고치기, 지우기

빠른 발급 칸에서 **규칙 이름**을 누르면 「규칙 수정」 창이 열려요. 내용을 고치고 **수정**을 누르거나, 왼쪽 아래 **삭제**를 눌러 규칙을 지워요.

<Note>
  규칙을 고치면 **그 뒤에 발급하는 쿠폰**부터 바뀌어요. 이미 발급한 쿠폰을 바꾸려면 쿠폰 목록에서 그 쿠폰의 **수정**을 눌러 주세요.
</Note>

## 잘 안 될 때

<AccordionGroup>
  <Accordion title="키오스크 결제 화면에 「쿠폰사용」 버튼이 없어요">
    키오스크에서 쿠폰이 꺼져 있어서 그래요. 키오스크에 연결된 키보드에서 **M** 키를 누르고 비밀번호 `admin123`으로 설정 화면에 들어간 뒤, **결제 설정**의 **결제 수단**에서 **쿠폰 결제**를 켜 주세요.
  </Accordion>

  <Accordion title="손님이 코드를 넣었는데 쓸 수 없다고 나와요">
    키오스크에 나온 글자에 따라 확인할 곳이 달라요.

    | 키오스크에 나온 글자 | 확인할 것 |
    | --- | --- |
    | 올바르지 않은 쿠폰 코드예요 | 코드를 잘못 넣었거나, 쿠폰이 꺼져(**비활성**) 있거나, 이 가게가 **적용 가게**에 없어요. |
    | 아직 사용할 수 없는 쿠폰이에요 | **시작일**이 아직 안 됐어요. 목록에서 상태가 **예정**이에요. |
    | 사용 기간이 끝난 쿠폰이에요 | **종료일**이 지났어요. **수정**에서 종료일을 늘릴 수 있어요. |
    | 사용 횟수가 끝난 쿠폰이에요 | **총 사용 제한**만큼 다 쓰였어요. **수정**에서 횟수를 늘릴 수 있어요. |
    | 최소 ○○원 이상 결제해야 쓸 수 있어요 | 가격이 **최소 구매 금액**보다 낮아요. |

    가게 화면을 따로 개발해 쓰는 가게에서는 글자가 조금 다르게 나올 수 있어요.
  </Accordion>

  <Accordion title="인터넷이 끊겼을 때 쿠폰이 안 돼요">
    쿠폰은 키오스크가 인터넷에 연결되어 있어야 쓸 수 있어요. 대시보드의 [장치 관리](/dashboard/devices)에서 키오스크가 연결되어 있는지 확인해 주세요.
  </Accordion>

  <Accordion title="「이미 존재하는 쿠폰 코드예요」라고 나와요">
    같은 가게에 같은 코드의 쿠폰이 이미 있어요. 다른 숫자로 정하거나 **코드 자동 생성**에 체크해 주세요.
  </Accordion>

  <Accordion title="꺼 둔 쿠폰을 여러 개 한 번에 켜고 싶어요">
    한 번에 켜는 버튼은 없어요. 쿠폰마다 스위치를 눌러 켜 주세요.
  </Accordion>
</AccordionGroup>
