**감자**는 포토이토에서 쓰는 포인트예요. 프레임을 키오스크에 보내거나 손님에게 카카오 알림톡을 보낼 때처럼, 일부 작업을 할 때 조금씩 써요.

이 화면에서 감자가 얼마나 남았는지 보고, 어디에 썼는지 확인하고, 모자라면 충전해요.

왼쪽 메뉴에서 **청구 및 구독 > 내 감자**를 누르면 열려요.

<Frame caption="내 감자 화면">
  <img src="/images/ko/potato/overview.png" alt="내 감자 화면. 위에 총 보유 개수와 소멸 예정 날짜가 있고, 아래에 사용 내역 표가 있다." />
</Frame>

<Tip>
  남은 감자는 대시보드 어느 화면에서나 오른쪽 위 **감자 ○○ 개**에서 볼 수 있어요.
</Tip>

## 남은 감자와 사라지는 날짜

화면 위쪽에 감자가 얼마나 남았는지 나와요.

<Frame>
  <img src="/images/ko/potato/balance.png" alt="내 감자 화면 위쪽. 총 보유에 1번, 만료 예정에 2번, 소멸 예정 목록에 3번 표시가 있다." />
</Frame>

1. **총 보유**: 지금 쓸 수 있는 감자를 모두 더한 개수예요.
2. **만료 예정**: 30일 안에 사라지는 감자 가운데 가장 먼저 사라지는 묶음의 개수예요. 옆에 며칠 남았는지도 나와요. 30일 안에 사라지는 감자가 없으면 0이에요.
3. **소멸 예정**: 감자가 사라지는 날짜와 그날 사라지는 개수예요. 충전한 날이 다르면 줄이 여러 개 나와요.

<Warning>
  **감자에는 쓸 수 있는 기한이 있어요.** **소멸 예정**에 적힌 날짜가 지나면 남은 감자는 사라져요.

  감자를 쓸 때는 먼저 사라지는 감자부터 써요.
</Warning>

## 탭 세 개

감자 개수 아래에 탭이 세 개 있어요.

<Frame>
  <img src="/images/ko/potato/tabs.png" alt="내 감자 화면의 탭. 사용 내역에 1번, 감자 충전에 2번, 감자 단가에 3번 표시가 있다." />
</Frame>

1. **사용 내역**: 감자가 언제, 왜 늘고 줄었는지 보여요.
2. **감자 충전**: 감자를 사요.
3. **감자 단가**: 어떤 작업에 감자가 몇 개 드는지 보여요.

## 사용 내역 보기

**사용 내역** 탭의 표는 한 줄이 감자가 한 번 늘거나 줄어든 기록이에요. 가장 최근 것이 맨 위예요.

| 칸 | 무엇이 적혀 있나요 |
| --- | --- |
| **일시** | 감자가 늘거나 줄어든 날짜와 시각 |
| **구분** | 왜 늘거나 줄었는지 |
| **변동** | 빨간색 `-`는 쓴 개수, 초록색 `+`는 들어온 개수 |
| **잔여** | 그 직후에 남은 감자 |
| **비고** | 들어온 감자라면 「만료 (날짜)」. 그 감자가 사라지는 날이에요. |

**구분** 칸에는 이런 글자가 나와요.

| 구분 | 무슨 뜻인가요 |
| --- | --- |
| **프레임 전송** | 프레임을 키오스크에 보냈어요. |
| **프레임 정보 수정** | 프레임의 이름이나 가격 등을 고쳤어요. |
| **첫화면 전송** | 첫화면을 키오스크에 보냈어요. |
| **첫화면 정보 수정** | 첫화면의 이름 등을 고쳤어요. |
| **카카오 알림톡** | 손님에게 카카오 알림톡을 보냈어요. |
| **공유 링크 생성** | 공유 링크를 만들었어요. |
| **재인쇄** | 사진을 다시 뽑았어요. |
| **AI 호출** | AI 기능을 썼어요. |
| **플랜 자동 지급** | 구독 요금이 결제되면서 플랜에 포함된 감자가 들어왔어요. |
| **감자 결제 충전** | **감자 충전** 탭에서 산 감자가 들어왔어요. |
| **환불** | 환불하면서 감자가 조정됐어요. |
| **관리자 조정** | 포토이토 운영팀이 감자를 넣거나 뺐어요. |

특정 내역만 보고 싶으면 표 위의 **구분** 버튼을 눌러 종류를 고르세요.

**비고**에 「N개 충전분에서 차감」이라고 나올 때가 있어요. 먼저 사라지는 감자가 모자라서 다음 감자까지 이어서 썼다는 뜻이에요. 신경 쓰지 않아도 돼요.

## 감자 충전하기

<Steps>
  <Step title="「감자 충전」 탭을 눌러요">
    살 수 있는 감자 상품이 왼쪽에 나와요.
  </Step>

  <Step title="살 상품의 「충전하기」를 눌러요">
    <Frame>
      <img src="/images/ko/potato/charge-button.png" alt="감자 충전 탭. 왼쪽에 감자 상품 네 개가 있고 첫 번째 상품의 충전하기 버튼에 빨간 표시가 있다. 오른쪽에는 카드사별 충전 한도 안내가 있다." />
    </Frame>

    상품마다 큰 글씨로 이름과 금액이 적혀 있어요. **이름 아래 작은 글씨가 실제로 들어오는 감자 개수**예요. 이름에 적힌 개수보다 많을 수 있어요.

    작은 글씨 옆에 「N일 유효」라고 적혀 있으면, 그 감자는 N일 동안 쓸 수 있어요.

    아직 결제되지 않아요. 확인 창이 떠요.
  </Step>

  <Step title="금액을 확인하고 결제 방법을 골라요">
    <Frame>
      <img src="/images/ko/potato/charge-dialog.png" alt="감자 충전 확인 창. 총 금액과 환불 안내가 있고, 등록된 결제수단으로 결제, 다른 카드로 결제, 닫기 버튼이 있다." />
    </Frame>

    - **등록된 결제수단(…)으로 결제**: [결제수단 관리](/dashboard/payment-methods)에 등록한 카드로 결제해요.
    - **다른 카드로 결제**: 결제 창이 새로 떠요. 거기에 다른 카드 정보를 넣어 결제해요. 등록한 카드가 없으면 이 버튼 이름이 **새로운 카드로 결제하기**예요.
    - **닫기**: 사지 않고 창을 닫아요.
  </Step>

  <Step title="결제가 끝났는지 확인해요">
    「결제가 완료됐어요.」라는 알림이 뜨고 **총 보유**가 늘어요. **사용 내역**에는 「감자 결제 충전」으로 적혀요.
  </Step>
</Steps>

<Warning>
  **「등록된 결제수단(…)으로 결제」를 누르면 한 번 더 묻지 않고 바로 결제돼요.** 창 위쪽의 상품 이름과 「총 ○○원이에요.」를 확인한 뒤 누르세요.
</Warning>

<Warning>
  **환불은 하나도 쓰지 않았을 때만 돼요.** 확인 창에 이렇게 적혀 있어요. 「사용하기 전이면 결제 내역에서 직접 전액 환불할 수 있어요. 한 개라도 사용하면 환불되지 않아요.」

  환불하는 방법은 [내 결제내역](/dashboard/payments#직접-환불하기)에 있어요.
</Warning>

<Note>
  감자 충전은 한 번만 결제돼요. 자동으로 다시 결제되지 않아요.

  상품과 금액은 바뀔 수 있어요. 지금 값은 **감자 충전** 탭에서 확인하세요.
</Note>

### 카드사별 충전 한도

**감자 충전** 탭 오른쪽에 **카드사별 충전 한도 안내** 표가 있어요. 카드사마다 하루나 한 달에 결제할 수 있는 금액이 정해져 있어요.

이 한도는 카드사가 정한 것이라 포토이토에서 바꿀 수 없고, 카드사 사정으로 달라질 수 있어요. 결제가 안 되면 이 표에서 쓰는 카드의 한도를 먼저 확인해 보세요.

## 감자가 드는 작업

**감자 단가** 탭에 어떤 작업에 감자가 몇 개 드는지 표로 나와요.

| 작업 | 언제 드나요 | 자세한 안내 |
| --- | --- | --- |
| **프레임 기기 전송** | 프레임을 키오스크에 보낼 때 | [프레임 관리](/dashboard/frames#감자가-드는-작업) |
| **프레임 메타데이터 수정** | 프레임의 이름이나 가격 등을 고치고 저장할 때 | [프레임 관리](/dashboard/frames#감자가-드는-작업) |
| **첫화면 기기 전송** | 첫화면을 키오스크에 보낼 때 | [첫화면 관리](/dashboard/themes#감자가-드는-작업) |
| **첫화면 메타데이터 수정** | 첫화면의 이름 등을 고치고 저장할 때 | [첫화면 관리](/dashboard/themes#감자가-드는-작업) |
| **카카오 알림톡 발송** | 손님에게 카카오 알림톡을 보낼 때 | |
| **공유 링크 생성** | 공유 링크를 새로 만들 때 | |
| **재인쇄** | 대시보드에서 사진을 다시 뽑을 때 | |

<Note>
  드는 감자 개수는 운영 정책에 따라 바뀔 수 있어요. 그래서 이 문서에는 개수를 적지 않았어요. 지금 값은 **감자 단가** 탭의 **감자 단가** 칸에서 확인하세요.
</Note>

감자가 모자라면 감자가 드는 작업은 되지 않아요. 먼저 충전한 뒤 다시 해 보세요.

## 잘 안 될 때

<AccordionGroup>
  <Accordion title="결제가 안 돼요">
    - 카드 한도를 넘었을 수 있어요. **감자 충전** 탭 오른쪽의 **카드사별 충전 한도 안내**를 확인하세요. 금액이 작은 상품으로 나눠 사거나 다른 카드를 써 보세요.
    - 「결제를 확인하고 있어요. 잠시 후 결제 내역에서 확인해 주세요.」라고 나오면 다시 결제하지 말고, 잠시 뒤 [내 결제내역](/dashboard/payments)의 **일반결제** 탭을 먼저 확인하세요. 같은 결제를 두 번 하지 않기 위해서예요.
  </Accordion>

  <Accordion title="결제했는데 감자가 안 늘었어요">
    오른쪽 위 **새로고침**을 눌러 보세요.

    그래도 그대로면 [내 결제내역](/dashboard/payments)의 **일반결제** 탭에 결제가 **결제 완료**로 있는지 확인하고, [채널톡으로 문의](/support)하세요.
  </Accordion>

  <Accordion title="감자가 갑자기 줄었어요">
    **사용 내역** 탭에서 **구분**을 보면 어디에 썼는지 알 수 있어요. 손님에게 카카오 알림톡이 나갈 때마다 감자를 쓰기 때문에, 손님이 많은 날에는 빨리 줄어요.

    **소멸 예정**에 적힌 날짜가 지나서 사라진 것일 수도 있어요.
  </Accordion>

  <Accordion title="「감자 충전」 탭에 상품이 안 보여요">
    - 「스토어를 불러오지 못했어요.」라고 나오면 잠시 뒤 **새로고침**을 눌러 보세요.
    - 「현재 판매 중인 감자 충전 상품이 없어요.」라고 나오면 지금 살 수 있는 상품이 없는 거예요. [채널톡으로 문의](/support)하세요.
  </Accordion>

  <Accordion title="「감자 단가」 표에 영어로 적힌 줄이 있어요">
    작업 이름이 `data_export`처럼 영어로 나오는 줄이 있을 수 있어요. 옆의 **설명** 칸을 읽으면 어떤 작업인지 알 수 있어요.
  </Accordion>
</AccordionGroup>
