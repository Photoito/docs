**포토이토 파트너**는 대시보드를 휴대폰에서 쓰는 앱이에요. 가게에 없을 때도 매출을 확인하고, 키오스크에 문제가 생기면 알림을 받을 수 있어요.

## 로그인하기

대시보드와 **같은 계정**으로 로그인해요. 따로 가입할 필요가 없어요.

앱을 처음 열면 알림을 허용할지 물어봐요. **허용**을 눌러야 문제가 생겼을 때 알림을 받을 수 있어요.

## 앱으로 하기 좋은 일, 컴퓨터로 해야 하는 일

앱은 **확인하고 알림 받는 용도**로 쓰기 좋아요. 파일을 올리거나 화면을 넓게 써야 하는 작업은 앱에서 제한적이라, 컴퓨터로 하는 것을 권해요.

| 앱에서 하기 좋아요 | 컴퓨터에서 하세요 |
| --- | --- |
| 오늘 매출, 인쇄 수 확인 | 프레임 올리기, 수정하기 |
| 이용 내역 확인 | 첫화면 올리기, 수정하기 |
| 키오스크 상태, 남은 용지 확인 | 필터 만들기 |
| 문제 알림 받기 | 프레임에 날짜, QR 코드 위치 맞추기 |
| 공지사항 읽기 | |

<Warning>
  **프레임이나 첫화면을 올리는 작업은 컴퓨터에서 해 주세요.** 앱에서는 파일을 올리거나 세밀하게 맞추는 작업이 제한적이에요.

  컴퓨터의 인터넷 브라우저(크롬 등)에서 [dashboard.photoito.kr](https://dashboard.photoito.kr)을 열면 돼요. 올리는 방법은 [프레임 관리](/dashboard/frames)에 있어요.
</Warning>

## 문제가 생기면 알림 받기

키오스크의 용지가 얼마 남지 않으면 앱으로 알림이 와요. 알림을 받으려면 두 가지가 되어 있어야 해요.

<Steps>
  <Step title="받을 사람이 앱에 로그인해 있어야 해요">
    사장님이든 직원이든, 알림을 받을 사람의 휴대폰에 앱이 깔려 있고 로그인되어 있어야 해요.
  </Step>

  <Step title="대시보드의 「알림 설정」에서 알림을 만들어요">
    **알림 설정** 메뉴에서 어떤 때 알릴지, 누구에게 보낼지 정해요. 앱에서는 **더보기 > 알림 설정**에 있어요.
  </Step>
</Steps>

<Note>
  지금은 **용지 부족** 알림을 받을 수 있어요. 받은 알림은 대시보드 위쪽의 종 모양 아이콘에서 다시 볼 수 있어요.
</Note>

## 잘 안 될 때

<AccordionGroup>
  <Accordion title="스토어에서 앱이 검색되지 않아요">
    한글 「포토이토」가 아니라 영어 **Photoito Partner**로 검색해 보세요. 그래도 안 나오면 위의 [앱 설치하기](#앱-설치하기) 링크를 눌러 주세요.
  </Accordion>

  <Accordion title="알림이 오지 않아요">
    순서대로 확인해 보세요.

    1. 휴대폰 설정에서 포토이토 파트너 앱의 **알림이 켜져 있는지** 확인해요.
    2. 앱에 **로그인되어 있는지** 확인해요. 로그아웃하면 알림이 오지 않아요.
    3. 대시보드의 **알림 설정**에 알림이 만들어져 있고, **받을 사람**에 내가 들어 있는지 확인해요. 받을 사람 목록에 「앱 미설치」라고 나오면 그 사람은 아직 앱에 로그인하지 않은 거예요.
  </Accordion>

  <Accordion title="앱에서 프레임이 올라가지 않아요">
    프레임과 첫화면을 올리는 작업은 앱에서 제한적이에요. 컴퓨터의 브라우저에서 [dashboard.photoito.kr](https://dashboard.photoito.kr)을 열어 올려 주세요.
  </Accordion>
</AccordionGroup>
