## 자주 나오는 말

| 말 | 뜻 |
| --- | --- |
| **키오스크** | 가게에 설치된 촬영 기계예요. |
| **대시보드** | 사장님이 휴대폰이나 컴퓨터로 여는 관리 화면이에요. [dashboard.photoito.kr](https://dashboard.photoito.kr)에서 열어요. |
| **프레임** | 손님이 촬영 전에 고르는 사진 틀이에요. |
| **첫화면** | 아무도 쓰고 있지 않을 때 키오스크에 떠 있는 화면이에요. |
| **감자** | 포토이토에서 쓰는 포인트예요. 알림톡 발송, 프레임 전송 같은 일부 작업에 써요. |
| **라이선스** | 키오스크 한 대를 쓸 수 있는 이용권이에요. |

<Note>
  이 가이드의 대시보드 화면 사진은 설명용으로 만든 가상의 가게 「포토이토 데모점」 화면이에요. 가게 이름, 매출, 손님 연락처는 모두 지어낸 값이에요.
</Note>
