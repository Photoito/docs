키오스크 프로그램을 켜면 가장 먼저 **키오스크를 켜고 있어요**라고 적힌 화면이 나와요. 다섯 가지를 차례로 확인한 뒤에 손님이 쓰는 화면으로 넘어가요.

화면에 나온 **문구를 그대로** 아래에서 찾아보세요.

<Note>
  이 화면의 사진은 설명용으로 만든 가짜 화면이에요. 활성화 키와 버전 숫자는 지어낸 값이에요.

  키오스크 프로그램이 예전 버전이면 화면의 글자가 영어(`System Boot`)로 나와요. 그럴 때는 맨 아래의 [예전 버전의 화면이라면](#예전-버전의-화면이라면)을 보세요.
</Note>

## 정상일 때는 이렇게 보여요

<Frame caption="왼쪽에 다섯 단계가 있고, 오른쪽에 진행률이 보여요.">
  <img src="/images/ko/kiosk-boot/progress.png" alt="키오스크 부팅 화면. 왼쪽에 라이선스 확인, 새 버전 확인, 프레임·첫화면 받기, 카메라·프린터 준비, 화면 준비 다섯 단계가 있고 앞의 두 단계에 파란 체크가 있다. 오른쪽에 진행률 숫자가 크게 보인다." />
</Frame>

| 단계 | 하는 일 |
| --- | --- |
| **라이선스 확인** | 이 키오스크를 쓸 수 있는 이용권이 있는지 확인해요. |
| **새 버전 확인** | 키오스크 프로그램의 새 버전이 있으면 받아서 설치해요. |
| **프레임·첫화면 받기** | 대시보드에서 보낸 프레임, 첫화면, 필터를 받아 와요. |
| **카메라·프린터 준비** | 카메라, 프린터, 결제를 맡는 프로그램을 켜요. |
| **화면 준비** | 받아 온 프레임과 첫화면을 화면에 쓸 수 있게 준비해요. |

단계 앞의 표시는 이런 뜻이에요.

| 표시 | 뜻 |
| --- | --- |
| 파란 체크 | 잘 끝났어요. |
| 도는 파란 원 | 지금 하는 중이에요. |
| 주황색 느낌표 | 문제가 있었지만 넘어갔어요. 키오스크는 켜져요. |
| 빨간 X | 문제가 있어요. 아래에서 문구를 찾아보세요. |

다 끝나면 **준비가 끝났어요**가 나오고 3초 뒤에 첫화면으로 넘어가요.

<Tip>
  오래 걸리는 단계에서는 진행률 아래에 「○초 지났어요」가 올라가요. 숫자가 올라가고 있으면 멈춘 게 아니에요.
</Tip>

## 라이선스 확인에서 멈출 때

빨간 상자에 **무슨 일인지**와 **무엇을 하면 되는지**가 함께 나와요. 그 아래에 활성화 키를 넣는 칸이 있어요.

<Frame>
  <img src="/images/ko/kiosk-boot/license-input.png" alt="부팅 화면의 라이선스 확인 단계에 빨간 X가 있다. 오른쪽에 「이 키오스크에 등록된 라이선스가 없어요. 대시보드의 내 라이선스에 있는 활성화 키를 입력해 주세요.」라는 빨간 문구와 활성화 키 입력 칸(1번), 활성화하기 버튼(2번)이 있다." />
</Frame>

### 빨간 상자의 문구로 찾기

| 화면의 문구 | 이럴 때 나와요 | 이렇게 하세요 |
| --- | --- | --- |
| **이 키오스크에 등록된 라이선스가 없어요.** | 키오스크를 처음 설치했거나, 컴퓨터를 초기화했어요. | [활성화 키를 넣어요](#활성화-키-넣기). |
| **라이선스 기간이 끝났어요.** | 구독 기간이 지났어요. | 대시보드의 **내 라이선스**에서 [다시 구독](/dashboard/license#체험-중이거나-만료됐을-때-구독하기)한 뒤, 키오스크에서 **다시 확인**을 눌러요. |
| **이 라이선스는 다른 키오스크에 연결되어 있어요.** | 다른 컴퓨터에 연결했던 라이선스예요. 컴퓨터를 바꾸면 나와요. | 이 키오스크의 활성화 키를 넣어요. 컴퓨터를 바꾼 거라면 [채널톡으로 문의](/support)해 주세요. |
| **이 라이선스는 사용이 중지되어 있어요.** | 포토이토에서 이 라이선스를 멈춰 두었어요. | [채널톡으로 문의](/support)해 주세요. |
| **컴퓨터의 날짜와 시간이 맞지 않아요.** | 컴퓨터의 시계가 과거로 돌아가 있어요. | 윈도우의 날짜와 시간을 「자동으로 설정」으로 맞추고 키오스크 프로그램을 다시 켜요. |
| **라이선스를 확인하지 못했어요.** | 위의 어느 것도 아닌 문제예요. | **다시 확인**을 눌러 보고, 안 되면 활성화 키를 넣어요. 문구 끝의 「오류 코드」를 [문의](/support)할 때 알려 주세요. |

### 「다시 확인」 버튼

<Frame>
  <img src="/images/ko/kiosk-boot/expired.png" alt="빨간 상자에 「라이선스 기간이 끝났어요. 대시보드의 내 라이선스에서 다시 구독한 뒤 다시 확인을 눌러 주세요.」라고 적혀 있다. 활성화 키 입력 칸 아래에 활성화하기 버튼과 다시 확인 버튼이 나란히 있고, 다시 확인 버튼에 빨간 표시가 있다." />
</Frame>

**다시 확인**은 키오스크에 예전 라이선스가 남아 있을 때만 보여요. 누르면 서버에서 최신 상태를 다시 받아 와요.

대시보드에서 방금 다시 구독했다면 이 버튼만 누르면 돼요. 활성화 키를 다시 넣을 필요가 없어요.

### 활성화 키 넣기

<Steps>
  <Step title="대시보드에서 활성화 키를 확인해요">
    휴대폰이나 다른 컴퓨터로 대시보드의 **청구 및 구독 > 내 라이선스**를 열어요. 라이선스 카드에 **활성화 키**가 있어요.
  </Step>

  <Step title="키오스크의 칸에 넣어요">
    키는 `XXXX-XXXX-XXXX-XXXX` 모양의 16글자예요. 줄표(-)는 저절로 들어가요.
  </Step>

  <Step title="「활성화하기」를 눌러요">
    잘 되면 다음 단계로 넘어가요.
  </Step>
</Steps>

<Tip>
  글자가 안 쳐지면 키보드가 한글로 되어 있는 거예요. **한/영** 키를 눌러 영어로 바꾸세요.

  **활성화하기**가 흐리게 보이고 눌리지 않으면 16글자가 아직 안 된 거예요.
</Tip>

### 활성화 키를 넣었는데 안 될 때

<Frame>
  <img src="/images/ko/kiosk-boot/activate-other-device.png" alt="활성화 키를 넣은 뒤의 화면. 빨간 상자에 「이 활성화 키는 다른 키오스크에 이미 연결되어 있어요. 이 키오스크의 활성화 키가 맞는지 확인해 주세요. 컴퓨터를 바꾼 경우에는 포토이토 채널톡으로 문의해 주세요.」라고 적혀 있다." />
</Frame>

| 화면의 문구 | 뜻 | 이렇게 하세요 |
| --- | --- | --- |
| **없는 활성화 키예요.** | 그런 키가 없어요. | 키를 잘못 쳤어요. 숫자 0과 영문 O, 숫자 1과 영문 I를 헷갈리지 않았는지 보고 다시 넣어요. |
| **이 활성화 키는 다른 키오스크에 이미 연결되어 있어요.** | 이 키는 다른 컴퓨터에서 쓰고 있어요. | 키오스크가 두 대라면 다른 키오스크의 키를 넣은 건 아닌지 확인해요. 컴퓨터를 바꾼 거라면 [채널톡으로 문의](/support)해 주세요. |
| **라이선스 기간이 끝났어요.** | 구독 기간이 지났어요. | 대시보드의 **내 라이선스**에서 [다시 구독](/dashboard/license#체험-중이거나-만료됐을-때-구독하기)한 뒤 다시 눌러요. |
| **이 라이선스는 사용이 중지되어 있어요.** | 포토이토에서 이 라이선스를 멈춰 두었어요. | [채널톡으로 문의](/support)해 주세요. |
| **너무 여러 번 눌렀어요.** | 1분에 5번까지만 돼요. | 1분 기다렸다가 다시 눌러요. |
| **인터넷에 연결되지 않았어요.** | 서버에 닿지 못했어요. | 인터넷 공유기와 랜선을 확인하고 다시 눌러요. |
| **서버에 문제가 생겼어요.** | 포토이토 서버 쪽 문제예요. | 몇 분 뒤에 다시 눌러요. 계속되면 [채널톡으로 문의](/support)해 주세요. |
| **활성화 키의 모양이 맞지 않아요.** | 16글자가 아니에요. | 글자 수를 확인하고 다시 넣어요. |
| **활성화는 됐지만 이 키오스크에서 확인하지 못했어요.** | 서버는 받아 줬는데 키오스크가 확인하지 못했어요. | 키오스크 프로그램을 껐다 켜요. |
| **활성화하지 못했어요.** | 위의 어느 것도 아닌 문제예요. | 다시 눌러 보고, 계속되면 문구 끝의 「오류 코드」와 함께 [채널톡으로 문의](/support)해 주세요. |

### 「라이선스를 다시 확인하고 있어요」가 계속 나와요

키오스크가 라이선스를 스스로 다시 받아 오려는 중이에요. 그 아래의 문구가 **기다리는 이유**예요.

<Frame>
  <img src="/images/ko/kiosk-boot/self-heal.png" alt="부팅 화면 오른쪽에 도는 원과 「라이선스를 다시 확인하고 있어요」, 그 아래 「인터넷에 연결되지 않았어요. 연결되면 자동으로 이어서 진행해요.」, 「31초 뒤에 다시 확인해요」라는 문구와 활성화 키 직접 입력하기 버튼이 있다." />
</Frame>

| 화면의 문구 | 뜻 | 이렇게 하세요 |
| --- | --- | --- |
| **인터넷에 연결되지 않았어요. 연결되면 자동으로 이어서 진행해요.** | 인터넷이 끊겼어요. | 공유기가 켜져 있는지, 키오스크의 랜선이 꽂혀 있는지 봐요. 인터넷이 돌아오면 저절로 풀려요. |
| **서버에서 라이선스를 확인하지 못했어요. 대시보드의 「내 라이선스」에서 상태를 확인해 주세요.** | 인터넷은 되는데 서버가 이 라이선스를 받아 주지 않았어요. 기간이 끝났을 때 주로 나와요. | 대시보드의 **내 라이선스**에서 「만료」인지 봐요. 만료라면 [다시 구독](/dashboard/license#체험-중이거나-만료됐을-때-구독하기)하면 다음 확인 때 저절로 풀려요. |

- 다시 확인하기까지 기다리는 시간은 2초, 4초, 8초로 늘어나다가 60초에서 멈춰요. 그 뒤로는 60초마다 다시 확인해요.
- 기다리지 않고 키를 직접 넣으려면 **활성화 키 직접 입력하기**를 눌러요.

<Frame>
  <img src="/images/ko/kiosk-boot/self-heal-server.png" alt="「서버에서 라이선스를 확인하지 못했어요. 대시보드의 내 라이선스에서 상태를 확인해 주세요.」와 「59초 뒤에 다시 확인해요」라는 문구 아래에 활성화 키 직접 입력하기 버튼이 있고, 버튼에 빨간 표시가 있다." />
</Frame>

## 새 버전 확인에서 나오는 문구

이 단계의 문제는 키오스크를 막지 않아요. 그대로 다음 단계로 넘어가요.

| 화면의 문구 | 뜻 | 이렇게 하세요 |
| --- | --- | --- |
| **최신 버전이에요** | 새 버전이 없어요. | 할 일이 없어요. |
| **새 버전(v○.○.○)을 받고 있어요...** | 새 버전을 받는 중이에요. | 기다려요. 인터넷이 느리면 몇 분 걸려요. |
| **새 버전을 설치해요. 키오스크가 곧 다시 켜져요.** | 새 버전을 설치해요. | 기다려요. 프로그램이 꺼졌다가 다시 켜지고, 이 화면이 처음부터 다시 나와요. |
| **새 버전을 받지 못했어요. 지금 버전으로 계속 진행해요.** | 받다가 실패했어요. | 다음에 켤 때 다시 받아요. 여러 날 되풀이되면 [채널톡으로 문의](/support)해 주세요. |
| **새 버전이 있는지 확인하지 못했어요 (계속 진행해요)** | 확인하지 못했어요. 지금 버전으로 켜져요. | 인터넷을 확인해요. |
| **인터넷에 연결되지 않아 건너뛰었어요** | 인터넷이 없어서 이 단계를 건너뛰었어요. | 아래 [인터넷이 끊긴 채로 켰을 때](#인터넷이-끊긴-채로-켰을-때)를 보세요. |

<Warning>
  **「새 버전을 받고 있어요...」에서 10분 넘게 멈춰 있으면** 키오스크 프로그램을 껐다 켜 주세요. 받는 도중에 인터넷이 끊기면 스스로 넘어가지 못하고 그대로 멈춰 있을 수 있어요.
</Warning>

## 프레임·첫화면 받기에서 나오는 문구

| 화면의 문구 | 뜻 |
| --- | --- |
| **모두 최신이에요** | 새로 받을 게 없어요. |
| **새로 받았어요: 프레임 3개, 첫화면 1개** | 대시보드에서 보낸 것을 받았어요. |
| **받지 못한 것이 있어요: 프레임 1개** | 일부를 받지 못했어요. 아래를 보세요. |
| **새 화면 디자인을 적용하려고 다시 시작해요…** | 가게 전용 화면 디자인을 새로 받았어요. 화면이 한 번 깜빡이고 처음부터 다시 켜져요. 문제가 아니에요. |

  <img src="/images/ko/kiosk-boot/sync-warning.png" alt="프레임·첫화면 받기 단계에 주황색 느낌표가 있고 「받지 못한 것이 있어요: 프레임 1개 · 새로 받았어요: 프레임 3개」라고 적혀 있다." />
</Frame>

대시보드에서 보낸 것 가운데 일부를 받지 못했어요. **키오스크는 그대로 켜져요.** 받지 못한 프레임이나 첫화면만 보이지 않아요.

문구에 나오는 이름은 이런 뜻이에요.

| 이름 | 무엇인가요 |
| --- | --- |
| 기본 파일 | 키오스크가 돌아가는 데 필요한 프로그램 파일 |
| 프레임 | 대시보드에서 보낸 프레임 |
| 첫화면 | 대시보드에서 보낸 첫화면 |
| 필터 | 대시보드에서 만든 필터 |
| 카테고리 | 프레임 카테고리 |
| 화면 디자인 | 가게 전용 화면 디자인(쓰는 가게만) |

이렇게 해 보세요.

1. 인터넷을 확인해요.
2. 부팅이 끝난 뒤 키오스크 설정 화면의 **프레임 관리**(첫화면은 **첫 화면 설정**)에서 **새로고침**을 눌러 다시 받아요. 방법은 [키오스크에서 프레임 켜기](/dashboard/frames#키오스크에서-프레임-켜기)에 있어요.
3. 되풀이되면 키오스크 프로그램을 껐다 켜요.

<Note>
  새로 받은 프레임은 꺼진 상태로 들어와요. 설정 화면에서 **활성화**를 체크해야 손님에게 보여요.
</Note>

### 「필요한 파일을 받지 못했어요」와 「다시 시도」 버튼

<Frame>
  <img src="/images/ko/kiosk-boot/blocked.png" alt="프레임·첫화면 받기 단계에 빨간 X와 「필요한 프로그램 파일이 없어요 (camera-agent.exe)」가 있다. 오른쪽에 「필요한 파일을 받지 못했어요. 키오스크에 필요한 프로그램 파일이 없어요. 인터넷 연결을 확인하고 다시 시도를 눌러 주세요.」라는 문구와 다시 시도 버튼이 있고, 버튼에 빨간 표시가 있다." />
</Frame>

**필요한 파일을 받지 못했어요**

카메라, 프린터, 결제, 사진 처리를 맡는 프로그램 파일 가운데 없는 것이 있어서 **키오스크가 켜지지 않아요.** 왼쪽의 괄호 안에 없는 파일의 이름이 나와요.

1. 인터넷을 확인해요.
2. **다시 시도**를 눌러요. 없는 파일을 다시 받아요.
3. 여러 번 눌러도 같으면 [채널톡으로 문의](/support)해 주세요. 괄호 안의 파일 이름을 함께 알려 주시면 빨라요.

## 카메라·프린터 준비에서 나오는 문구

카메라, 프린터, 결제를 맡는 프로그램이 켜지기를 최대 30초 기다려요. 「준비됨 2/3 — 결제, 프린터」처럼 준비된 것이 차례로 나와요.

### 「카메라 프로그램이 켜지지 않았어요」

<Frame>
  <img src="/images/ko/kiosk-boot/agent-fail.png" alt="카메라·프린터 준비 단계에 빨간 X와 「카메라 프로그램이 켜지지 않았어요」가 있다. 오른쪽 진행률 아래에 「카메라 프로그램이 켜지지 않았어요. 촬영이나 인쇄가 안 될 수 있으니 키오스크 컴퓨터를 껐다 켜 주세요.」라는 빨간 문구가 있다." />
</Frame>

**카메라 프로그램이 켜지지 않았어요 / 프린터 프로그램이 켜지지 않았어요**

카메라나 프린터를 맡는 **프로그램**이 30초 안에 켜지지 않았어요. 카메라 선이 빠진 것과는 다른 문제예요.

<Warning>
  이 문구가 나와도 **부팅은 끝까지 진행되고 첫화면으로 넘어가요.** 문구는 잠깐 보이다가 사라져요. 하지만 그 상태로는 촬영이나 인쇄가 되지 않을 수 있어요.
</Warning>

1. 키오스크 컴퓨터를 **껐다가 다시 켜요.**
2. 다시 켰을 때도 같은 문구가 나오면 [채널톡으로 문의](/support)해 주세요.

### 「결제 프로그램이 켜지지 않았어요 (계속 진행해요)」

결제를 맡는 프로그램이 켜지지 않았어요. 주황색 느낌표가 붙고 키오스크는 켜져요. **카드나 현금 결제가 되지 않을 수 있어요.** 컴퓨터를 껐다 켜고, 같으면 [채널톡으로 문의](/support)해 주세요.

## 화면 준비에서 나오는 문구

| 화면의 문구 | 뜻 |
| --- | --- |
| **프레임을 읽고 있어요 12/40개 (30%)** | 프레임을 하나씩 읽는 중이에요. 프레임이 많으면 오래 걸려요. |
| **첫화면을 준비하고 있어요 1/2개 (50%)** | 켜 둔 첫화면을 준비하는 중이에요. |
| **프레임 그림을 준비하고 있어요 30/40개 (75%)** | 프레임 미리보기 그림을 준비하는 중이에요. |
| **준비가 끝났어요** | 끝났어요. |
| **일부를 읽지 못했어요 (계속 진행해요)** | 일부를 읽지 못했어요. 키오스크는 켜져요. |

「일부를 읽지 못했어요」가 나오고 프레임이나 첫화면이 보이지 않으면, 키오스크 설정 화면에서 **새로고침**을 눌러 다시 받아 보세요.

## 인터넷이 끊긴 채로 켰을 때

<Frame>
  <img src="/images/ko/kiosk-boot/offline.png" alt="새 버전 확인과 프레임·첫화면 받기 단계에 파란 체크가 있고 둘 다 「인터넷에 연결되지 않아 건너뛰었어요」라고 적혀 있다." />
</Frame>

**인터넷에 연결되지 않아 건너뛰었어요**

라이선스가 이미 연결된 키오스크는 인터넷이 없어도 켜져요. 새 버전 확인과 프레임·첫화면 받기만 건너뛰어요.

- 대시보드에서 새로 보낸 프레임과 첫화면은 들어오지 않아요. 인터넷이 돌아온 뒤 키오스크 설정 화면에서 **새로고침**을 누르면 들어와요.
- 새 버전도 받지 않아요. 다음에 켤 때 받아요.

인터넷이 끊긴 채로 촬영하면 손님이 QR 코드로 사진을 받지 못할 수 있어요. [업로드 오류](/troubleshooting/upload)를 함께 보세요.

## 문의하기 전에

문의는 [채널톡](/support)으로 받아요. 아래 세 가지를 함께 보내 주시면 훨씬 빨리 도와드릴 수 있어요.

1. **화면 사진**: 휴대폰으로 화면 전체를 찍어 주세요.
2. **어느 단계에서 멈췄는지**: 왼쪽 다섯 단계 가운데 빨간 X나 도는 원이 있는 곳이에요.
3. **버전**: 화면 왼쪽 아래의 버전 숫자예요.

<Note>
  부팅 화면이 떠 있는 동안에는 키오스크 설정 화면이 열리지 않아요. 부팅이 끝난 뒤에 열 수 있어요.
</Note>
