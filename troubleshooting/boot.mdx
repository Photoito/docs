---

키오스크 프로그램을 켜면 가장 먼저 **System Boot**라고 적힌 화면이 나와요. 다섯 가지를 차례로 확인한 뒤에 손님이 쓰는 화면으로 넘어가요.

화면에 나온 **문구를 그대로** 아래에서 찾아보세요.

<Note>
  이 화면의 사진은 설명용으로 만든 가짜 화면이에요. 활성화 키와 버전 숫자는 지어낸 값이에요.
</Note>

## 정상일 때는 이렇게 보여요

<Frame caption="왼쪽에 다섯 단계가 있고, 오른쪽에 진행률이 보여요.">
  <img src="/images/ko/kiosk-boot/progress.png" alt="키오스크 부팅 화면. 왼쪽에 라이선스 확인, 키오스크 업데이트, 리소스 동기화, 에이전트 시작, 리소스 로딩 다섯 단계가 있고 앞의 두 단계에 파란 체크가 있다. 오른쪽에 진행률 숫자가 크게 보인다." />
</Frame>

| 단계 | 하는 일 |
| --- | --- |
| **라이선스 확인** | 이 키오스크를 쓸 수 있는 이용권이 있는지 확인해요. |
| **키오스크 업데이트** | 새 버전이 있으면 받아서 설치해요. |
| **리소스 동기화** | 대시보드에서 보낸 프레임, 첫화면, 필터를 받아 와요. |
| **에이전트 시작** | 카메라, 프린터, 결제를 맡는 프로그램을 켜요. |
| **리소스 로딩** | 받아 온 프레임과 첫화면을 화면에 쓸 수 있게 준비해요. |

단계 앞의 표시는 이런 뜻이에요.

| 표시 | 뜻 |
| --- | --- |
| 파란 체크 | 잘 끝났어요. |
| 도는 파란 원 | 지금 하는 중이에요. |
| 주황색 느낌표 | 문제가 있었지만 넘어갔어요. 키오스크는 켜져요. |
| 빨간 X | 문제가 있어요. 아래에서 문구를 찾아보세요. |

다 끝나면 **시스템 준비 완료**가 나오고 3초 뒤에 첫화면으로 넘어가요.

<Tip>
  오래 걸리는 단계에서는 진행률 아래에 「○초 경과」가 올라가요. 숫자가 올라가고 있으면 멈춘 게 아니에요.
</Tip>

## 라이선스 확인에서 멈출 때

### 활성화 키를 넣는 칸이 나와요

<Frame>
  <img src="/images/ko/kiosk-boot/license-input.png" alt="부팅 화면의 라이선스 확인 단계에 빨간 X가 있다. 오른쪽에 「유효한 라이선스가 없습니다 라이선스 키를 입력해주세요.」라는 빨간 문구와 활성화 키 입력 칸(1번), 라이선스 활성화 버튼(2번)이 있다." />
</Frame>

**유효한 라이선스가 없습니다 라이선스 키를 입력해주세요.**

이 키오스크에 쓸 수 있는 라이선스가 없다는 뜻이에요. 이럴 때 나와요.

- 키오스크를 처음 설치했어요.
- 컴퓨터를 초기화했거나 바꿨어요.
- 라이선스 기간이 끝났어요.
- 컴퓨터의 날짜와 시간이 과거로 돌아가 있어요.

어느 경우든 처음에는 같은 문구가 나와요.

<Steps>
  <Step title="컴퓨터의 날짜와 시간이 맞는지 봐요">
    날짜가 엉뚱하면 윈도우의 날짜와 시간을 「자동으로 설정」으로 맞추고 키오스크 프로그램을 다시 켜요.
  </Step>

  <Step title="대시보드에서 라이선스 상태를 봐요">
    휴대폰이나 다른 컴퓨터로 대시보드의 **청구 및 구독 > 내 라이선스**를 열어요. 「만료」라고 나오면 먼저 [다시 구독](/dashboard/license#체험-중이거나-만료됐을-때-구독하기)해 주세요.
  </Step>

  <Step title="「기존 라이선스 재검증」 버튼이 있으면 먼저 눌러요">
    이 버튼은 키오스크에 예전 라이선스가 남아 있을 때만 보여요. 누르면 서버에서 최신 상태를 다시 받아 와요. 방금 다시 구독했다면 이것만으로 풀려요.

    <Frame>
      <img src="/images/ko/kiosk-boot/expired.png" alt="활성화 키 입력 칸 아래에 라이선스 활성화 버튼과 기존 라이선스 재검증 버튼이 나란히 있고, 기존 라이선스 재검증 버튼에 빨간 표시가 있다." />
    </Frame>
  </Step>

  <Step title="버튼이 없거나 풀리지 않으면 활성화 키를 넣어요">
    **내 라이선스**의 카드에 있는 **활성화 키**를 칸에 넣고 **라이선스 활성화**를 눌러요. 키는 `XXXX-XXXX-XXXX-XXXX` 모양의 16글자예요. 줄표(-)는 저절로 들어가요.
  </Step>
</Steps>

<Tip>
  글자가 안 쳐지면 키보드가 한글로 되어 있는 거예요. **한/영** 키를 눌러 영어로 바꾸세요.
</Tip>

### 「라이선스를 다시 검증하고 있어요」가 계속 나와요

<Frame>
  <img src="/images/ko/kiosk-boot/self-heal.png" alt="부팅 화면 오른쪽에 도는 원과 「라이선스를 다시 검증하고 있어요」, 그 아래 「다음 31초 뒤에 자동으로 재검증할게요」라는 문구가 있다." />
</Frame>

**라이선스를 다시 검증하고 있어요 / 다음 ○초 뒤에 자동으로 재검증할게요**

키오스크가 라이선스를 스스로 다시 받아 오려는 중이에요. 대부분 **인터넷이 끊겨서** 나와요.

- 기다리는 시간은 2초, 4초, 8초로 늘어나다가 60초에서 멈춰요. 그 뒤로는 60초마다 다시 해 봐요.
- 인터넷이 돌아오면 저절로 풀려요. 아무것도 누르지 않아도 돼요.

몇 분이 지나도 그대로면 이렇게 해 보세요.

1. 가게의 인터넷 공유기가 켜져 있는지, 키오스크의 랜선이 꽂혀 있는지 확인해요.
2. 공유기를 껐다 켜요.
3. 대시보드의 **내 라이선스**에서 라이선스가 「만료」가 아닌지 확인해요.

<Warning>
  인터넷은 되는데 서버가 이 라이선스를 받아 주지 않을 때도(기간이 끝났을 때 등) 이 화면이 되풀이돼요. **화면에는 그 이유가 나오지 않아요.** 인터넷이 멀쩡한데 5분 넘게 계속되면 [문의](mailto:support@photoito.kr)해 주세요.
</Warning>

### 「기존 라이선스 재검증」을 눌렀더니 영어 문구가 나와요

<Frame>
  <img src="/images/ko/kiosk-boot/expired-recheck.png" alt="빨간 문구로 「License expired 새로운 라이선스 키를 입력하거나 다시 시도하세요.」라고 나와 있다." />
</Frame>

영어 부분이 이유예요. 뒤에는 「새로운 라이선스 키를 입력하거나 다시 시도하세요.」가 붙어요.

| 화면의 문구 | 뜻 | 이렇게 하세요 |
| --- | --- | --- |
| `License expired` | 라이선스 기간이 끝났어요. | 대시보드의 **내 라이선스**에서 [다시 구독](/dashboard/license#체험-중이거나-만료됐을-때-구독하기)한 뒤, **기존 라이선스 재검증**을 한 번 더 눌러요. |
| `License HWID mismatch` | 이 라이선스는 다른 컴퓨터에 연결된 거예요. | 컴퓨터를 바꿨다면 [문의](mailto:support@photoito.kr)해서 연결을 옮겨 달라고 하세요. |
| `License usage is blocked (can_use=false)` | 포토이토에서 이 라이선스를 쓰지 못하게 막아 두었어요. | [문의](mailto:support@photoito.kr)해 주세요. |
| `라이선스 검증 실패` | 이유를 알 수 없어요. | 활성화 키를 다시 넣어요. |

### 활성화 키를 넣었는데 「활성화 실패」가 나와요

<Frame caption="영어와 기호 사이에 있는 한글 문장이 이유예요.">
  <img src="/images/ko/kiosk-boot/activate-other-device.png" alt="활성화 키를 넣은 뒤의 화면. 빨간 문구가 「활성화 실패: Activate failed: 409 HTTP 409 Conflict:」로 시작하고 중괄호와 따옴표 사이에 「라이선스가 다른 디바이스에서 이미 활성화되어 있어요.」라는 한글 문장이 들어 있다." />
</Frame>

**활성화 실패: Activate failed: …**

문구가 길고 영어와 기호가 섞여 나와요. 그 안의 **한글 문장** 또는 **숫자**를 아래에서 찾으세요.

| 문구 안에 들어 있는 말 | 숫자 | 뜻 | 이렇게 하세요 |
| --- | --- | --- | --- |
| 유효하지 않은 Activation key예요. | 404 | 그런 활성화 키가 없어요. | 키를 잘못 쳤어요. 숫자 0과 알파벳 O, 숫자 1과 알파벳 I를 헷갈리지 않았는지 보고 다시 넣어요. |
| 라이선스가 다른 디바이스에서 이미 활성화되어 있어요. | 409 | 이 키는 이미 다른 컴퓨터에 연결되어 있어요. | 키오스크가 두 대라면 다른 키오스크의 키를 넣은 건 아닌지 확인해요. 컴퓨터를 바꾼 거라면 [문의](mailto:support@photoito.kr)해서 연결을 옮겨 달라고 하세요. |
| 라이선스가 만료되었어요. | 403 | 라이선스 기간이 끝났어요. | 대시보드의 **내 라이선스**에서 [다시 구독](/dashboard/license#체험-중이거나-만료됐을-때-구독하기)한 뒤 다시 눌러요. |
| 라이선스 사용이 비활성화되어 있어요. | 403 | 포토이토에서 이 라이선스를 막아 두었어요. | [문의](mailto:support@photoito.kr)해 주세요. |
| 요청이 너무 많아요. 잠시 후 다시 시도해 주세요. | 429 | 짧은 시간에 너무 여러 번 눌렀어요. 1분에 5번까지만 돼요. | 1분 기다렸다가 다시 눌러요. |
| 라이선스 활성화에 실패했어요. | 500 | 서버에 문제가 있어요. | 몇 분 뒤에 다시 해 보고, 계속되면 [문의](mailto:support@photoito.kr)해 주세요. |
| `Request timeout after 8000ms` | 0 | 8초 동안 서버의 답이 없었어요. | 인터넷이 느리거나 끊겼어요. 공유기를 확인하고 다시 눌러요. |
| `fetch failed` | 0 | 서버에 닿지 못했어요. | 인터넷이 끊겼어요. 공유기와 랜선을 확인해요. |

그 밖에 이런 문구도 나올 수 있어요.

| 화면의 문구 | 뜻 | 이렇게 하세요 |
| --- | --- | --- |
| **활성화 키를 입력해주세요.** | 칸이 비어 있어요. | 활성화 키를 넣어요. |
| **라이선스 활성화는 성공했지만 검증에 실패했습니다.** | 서버는 받아 줬는데 키오스크가 확인하지 못했어요. | 키오스크 프로그램을 껐다 켜요. 같으면 [문의](mailto:support@photoito.kr)해 주세요. |
| `Activated license HWID mismatch` | 받은 라이선스가 이 컴퓨터의 것이 아니에요. | [문의](mailto:support@photoito.kr)해 주세요. |

<Note>
  **라이선스 활성화** 버튼이 흐리게 보이고 눌리지 않으면 키가 16글자가 안 된 거예요.
</Note>

## 키오스크 업데이트에서 나오는 문구

이 단계의 문제는 키오스크를 막지 않아요. 그대로 다음 단계로 넘어가요.

| 화면의 문구 | 뜻 | 이렇게 하세요 |
| --- | --- | --- |
| **최신 버전입니다** | 새 버전이 없어요. | 할 일이 없어요. |
| **v○.○.○ 다운로드 중...** | 새 버전을 받는 중이에요. | 기다려요. 인터넷이 느리면 몇 분 걸려요. |
| **업데이트 설치 중... 앱이 재시작됩니다.** | 새 버전을 설치해요. | 기다려요. 프로그램이 꺼졌다가 다시 켜지고, 부팅 화면이 처음부터 다시 나와요. |
| **다운로드 실패 (계속 진행)** | 새 버전을 받지 못했어요. 지금 버전으로 켜져요. | 다음에 켤 때 다시 받아요. 여러 날 되풀이되면 [문의](mailto:support@photoito.kr)해 주세요. |
| **업데이트 확인 실패 (계속 진행)** | 새 버전이 있는지 확인하지 못했어요. 지금 버전으로 켜져요. | 인터넷을 확인해요. |
| **네트워크 오프라인 — 건너뜀** | 인터넷이 없어서 이 단계를 건너뛰었어요. | 아래 [인터넷이 끊긴 채로 켰을 때](#인터넷이-끊긴-채로-켰을-때)를 보세요. |

<Warning>
  **「다운로드 중...」에서 10분 넘게 멈춰 있으면** 키오스크 프로그램을 껐다 켜 주세요. 받는 도중에 인터넷이 끊기면 스스로 넘어가지 못하고 그대로 멈춰 있을 수 있어요.
</Warning>

## 리소스 동기화에서 나오는 문구

### 주황색 느낌표와 「일부 실패」 또는 「전체 실패」

<Frame>
  <img src="/images/ko/kiosk-boot/sync-warning.png" alt="리소스 동기화 단계에 주황색 느낌표가 있고 「일부 실패 — 공통 최신 · 매장 프레임 3/4 (1개 실패) · 매장 테마 최신 · 매장 필터 최신 · 매장 카테고리 최신 · 매장 디자인 최신」이라고 적혀 있다." />
</Frame>

대시보드에서 보낸 것 가운데 일부를 받지 못했어요. **키오스크는 그대로 켜져요.** 받지 못한 프레임이나 첫화면만 보이지 않아요.

문구는 여섯 가지를 차례로 알려 줘요.

| 문구 속 이름 | 무엇인가요 |
| --- | --- |
| 공통 | 키오스크가 돌아가는 데 필요한 프로그램 파일 |
| 매장 프레임 | 대시보드에서 보낸 프레임 |
| 매장 테마 | 대시보드에서 보낸 첫화면 |
| 매장 필터 | 대시보드에서 만든 필터 |
| 매장 카테고리 | 프레임 카테고리 |
| 매장 디자인 | 가게 전용 화면 디자인(쓰는 가게만) |

이름 뒤의 말은 이런 뜻이에요.

| 이름 뒤의 말 | 뜻 |
| --- | --- |
| 최신 | 새로 받을 게 없어요. |
| 3개 | 새로 3개를 받았어요. |
| 3/4 (1개 실패) | 4개 중 3개만 받았어요. |
| 실패 | 하나도 받지 못했어요. |

이렇게 해 보세요.

1. 인터넷을 확인해요.
2. 부팅이 끝난 뒤 키오스크 설정 화면의 **프레임 관리**(첫화면은 **첫 화면 설정**)에서 **새로고침**을 눌러 다시 받아요. 방법은 [키오스크에서 프레임 켜기](/dashboard/frames#키오스크에서-프레임-켜기)에 있어요.
3. 되풀이되면 키오스크 프로그램을 껐다 켜요.

<Note>
  새로 받은 프레임은 꺼진 상태로 들어와요. 설정 화면에서 **활성화**를 체크해야 손님에게 보여요.
</Note>

### 「리소스 다운로드 실패」와 「재시도」 버튼

<Frame>
  <img src="/images/ko/kiosk-boot/blocked.png" alt="리소스 동기화 단계에 빨간 X와 「필수 파일 누락: camera-agent.exe」가 있다. 오른쪽에 「리소스 다운로드 실패. 필수 파일을 다운로드하지 못했습니다. 네트워크 연결을 확인하고 다시 시도해 주세요.」라는 문구와 재시도 버튼이 있고, 버튼에 빨간 표시가 있다." />
</Frame>

**리소스 다운로드 실패 / 필수 파일을 다운로드하지 못했습니다.**

왼쪽에는 **필수 파일 누락: ○○.exe**라고 나와요. 카메라, 프린터, 결제, 사진 처리를 맡는 프로그램 파일 가운데 없는 것이 있어서 **키오스크가 켜지지 않아요.**

1. 인터넷을 확인해요.
2. **재시도**를 눌러요. 없는 파일을 다시 받아요.
3. 여러 번 눌러도 같으면 [문의](mailto:support@photoito.kr)해 주세요. 왼쪽에 나온 파일 이름을 함께 알려 주시면 빨라요.

### 「새 매장 디자인 적용 — 재시작합니다…」

가게 전용 화면 디자인을 새로 받았어요. 화면이 한 번 깜빡이고 부팅이 처음부터 다시 돼요. 문제가 아니에요.

## 에이전트 시작에서 나오는 문구

카메라, 프린터, 결제를 맡는 프로그램이 켜지기를 최대 30초 기다려요. 「에이전트 준비 2/3 — 결제, 프린터」처럼 준비된 것이 차례로 나와요.

### 「○○ 에이전트에 연결할 수 없습니다.」

<Frame>
  <img src="/images/ko/kiosk-boot/agent-fail.png" alt="에이전트 시작 단계에 빨간 X와 「중요 에이전트 연결 실패: 카메라」가 있다. 오른쪽 진행률 아래에 「카메라 에이전트에 연결할 수 없습니다.」라는 빨간 문구가 있다." />
</Frame>

**카메라 에이전트에 연결할 수 없습니다. / 프린터 에이전트에 연결할 수 없습니다.**

카메라나 프린터를 맡는 **프로그램**이 30초 안에 켜지지 않았어요. 카메라 선이 빠진 것과는 다른 문제예요.

<Warning>
  이 문구가 나와도 **부팅은 끝까지 진행되고 첫화면으로 넘어가요.** 문구는 잠깐 보이다가 사라져요. 하지만 그 상태로는 촬영이나 인쇄가 되지 않을 수 있어요.
</Warning>

1. 키오스크 컴퓨터를 **껐다가 다시 켜요.**
2. 다시 켰을 때도 같은 문구가 나오면 [문의](mailto:support@photoito.kr)해 주세요.

### 「일부 에이전트 연결 실패: 결제 (계속 진행)」

결제를 맡는 프로그램이 켜지지 않았어요. 주황색 느낌표가 붙고 키오스크는 켜져요. **카드나 현금 결제가 되지 않을 수 있어요.** 컴퓨터를 껐다 켜고, 같으면 [문의](mailto:support@photoito.kr)해 주세요.

## 리소스 로딩에서 나오는 문구

| 화면의 문구 | 뜻 |
| --- | --- |
| **프레임 로딩 12/40개 (30%)** | 프레임을 하나씩 읽는 중이에요. 프레임이 많으면 오래 걸려요. |
| **테마 캐시 1/2개 (50%)** | 켜 둔 첫화면을 준비하는 중이에요. |
| **이미지 메모리 로딩 30/40개 (75%)** | 프레임 미리보기 그림을 준비하는 중이에요. |
| **리소스 로딩 완료 (캐시 재사용)** | 끝났어요. 바뀐 게 없어서 지난번에 준비한 것을 그대로 썼어요. |
| **리소스 로딩 일부 실패 (계속 진행)** | 일부를 읽지 못했어요. 키오스크는 켜져요. |

「일부 실패」가 나오고 프레임이나 첫화면이 보이지 않으면, 키오스크 설정 화면에서 **새로고침**을 눌러 다시 받아 보세요.

## 인터넷이 끊긴 채로 켰을 때

<Frame>
  <img src="/images/ko/kiosk-boot/offline.png" alt="키오스크 업데이트와 리소스 동기화 단계에 파란 체크가 있고 둘 다 「네트워크 오프라인 — 건너뜀」이라고 적혀 있다." />
</Frame>

**네트워크 오프라인 — 건너뜀**

라이선스가 이미 연결된 키오스크는 인터넷이 없어도 켜져요. 업데이트와 리소스 동기화만 건너뛰어요.

- 대시보드에서 새로 보낸 프레임과 첫화면은 들어오지 않아요. 인터넷이 돌아온 뒤 키오스크 설정 화면에서 **새로고침**을 누르면 들어와요.
- 새 버전도 받지 않아요. 다음에 켤 때 받아요.

인터넷이 끊긴 채로 촬영하면 손님이 QR 코드로 사진을 받지 못할 수 있어요. [업로드 오류](/troubleshooting/upload)를 함께 보세요.

아래 세 가지를 알려 주시면 훨씬 빨리 도와드릴 수 있어요.

1. **화면 사진**: 휴대폰으로 화면 전체를 찍어 주세요. 문구가 길어도 그대로 보내 주시면 돼요.
2. **어느 단계에서 멈췄는지**: 왼쪽 다섯 단계 가운데 빨간 X나 도는 원이 있는 곳이에요.

<Note>
  부팅 화면이 떠 있는 동안에는 키오스크 설정 화면이 열리지 않아요. 부팅이 끝난 뒤에 열 수 있어요.
</Note>
